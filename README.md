🛠️ Tecnologias e Ferramentas Utilizadas:
Linguagem: Java (Desenvolvimento nativo orientado a objetos para regras de negócio e controle de fluxo).

Interface Gráfica (UI): XML (Linguagem de marcação para estruturação de layouts, telas, cartões e componentes visuais responsivos).

Gerenciador de Build & Dependências: Gradle (Gerenciamento de pacotes, compilação e automação do ciclo de vida do projeto).

Banco de Dados Local: SQLite (Persistência estruturada em tabelas relacionais com chaves estrangeiras utilizando SQLiteOpenHelper).

Arquitetura & Padrões: Padrão DAO (Data Access Object) para isolar a persistência dos dados e Adapters Customizados para renderização de listas dinâmicas.
